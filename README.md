# 北极星指标看板 MVP

面向业务运营的看板构建工具。React + Vite 前端，Node.js + SQLite 本地后端。

## 启动

需要 Node.js 24（使用内置 SQLite）。

```sh
npm install
npm run build
npm start
```

打开 http://127.0.0.1:4318 。开发模式为 `npm run dev`。服务绑定本机回环地址；当前为本地单用户 MVP。

## 已实现

- 商业分析工作台 UI：看板列表、指标中心、模板、内置 UI 规范页。
- 空白或模板创建、AI 辅助创建、看板搜索、复制和删除草稿。
- 指标卡、折线、柱状、饼图、表格；按维度、时间粒度、展示计算、样式与大小配置。
- 指标与内容拖入画布、网格吸附、碰撞避让、标题拖动、边角缩放；数字布局与 Alt + 方向键替代操作。
- 图片上传与链接、文本编辑、HTTPS 网页嵌入。部分目标站点限制嵌入，可打开原网页。
- 7/30/60 天及渠道筛选；比例重算、最新日去重口径、可加指标累计；指标说明和明细。
- SQLite 自动保存、保存失败恢复副本、撤销重做、不可变发布快照、发布版本链接、JSON 导出。
- AI 指标多选、分析方式、业务目标、方案预览、抽屉收起恢复、应用为单次可撤销操作。

## 数据与 AI 接入

初始增长数据为内置样例，时间截止 2026-10-12。真实数据接入点在 `src/model.mjs` 的 `query`，指标元数据位于 `metrics`。样例按互斥渠道生成，日活总计只取最新日；转化率和获客成本聚合分子分母。

默认运行可用的**规则生成模式**：根据已选指标及分析方式构建真实普通组件，业务目标存入分析说明。该模式不提供通用自然语言理解，界面明确标识模式。配置 `.env` 的 `AI_API_KEY`、`AI_MODEL`，可选 `AI_BASE_URL` 后重启，可启用模型生成。凭据只在服务端读取，前端不接收密钥。模型输出须通过同一指标和组件校验。

模型接入参考 [Chat Completions 官方接口](https://developers.openai.com/api/reference/resources/chat)。真实模型调用需要用户提供有效凭据，因此当前交付未执行外部模型测试。

## 持久化

- `.data/northstar.sqlite`：草稿与独立发布快照。
- `.data/uploads/`：上传图片（最多 5MB，校验文件签名）。
- 可设置 `NORTHSTAR_DATA_DIR` 替换数据目录。
- 本机链接可在同一服务环境访问；公开部署、登录、多用户权限、外部数据服务留待接入。
- 已发布版本不会随着草稿修改而改变。网页和图片来源内容本身可能随外部服务变化。
