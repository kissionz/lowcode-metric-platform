# 北极星 MVP 交付

## 入口
运行中的构建版本：http://127.0.0.1:4320 。UI 规范页：http://127.0.0.1:4320/#spec 。默认自行启动端口为 4318。

## 推荐体验
1. 打开“增长经营总览”，调整全局日期和渠道。
2. 选择组件，在右侧切换图表、维度与样式，应用后继续调布局。
3. 从左侧添加文本、图片或网页；拖动标题移动，拖动右下角缩放。
4. 使用 AI 一键生成，选择指标与分析方式，生成方案后应用。
5. 点击发布保存独立版本，使用分享入口取得本机查看链接。
6. 新建空白看板或使用模板，验证从头构建。

产品方案见 `design/产品方案.md`，视觉规范见 `docs/UI规范.md`，验证记录见 `docs/验收记录.md`。模型和数据接入、持久化路径及启动命令见项目 README。
