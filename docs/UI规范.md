# 北极星 UI 规范 v1.0

## 产品风格
商业分析工作台。以稳定导航、分层工作区、清晰数据和完整反馈建立产品质感。蓝色承担主要操作与选择状态；深色导航用于稳定产品结构；图表色区分数据序列。

## 字体与尺寸
系统中文字体 PingFang SC / Microsoft YaHei，数字使用系统无衬线与 tabular-nums。页面标题 28px/600，区域标题 18px/600，组件标题 14px/600，正文 14px，辅助信息 12px，指标数值 32px/650。业务正文保持清晰对比，最小可读辅助文本 12px。

## 布局
- 列表：176px 深色导航，64px 顶栏，内容边距 32px。
- 编辑器：64px 紧凑导航、244px 组件库、中间自适应画布、300px 配置面板；AI 抽屉宽 420px，替代右侧配置面板，可收起。
- 画布 12 列，组件间距 16px，行单位 40px。组件支持碰撞避让与网格吸附。
- 小于 1180px 自动收起组件库；可通过按钮重新打开。小于 760px 查看布局单列堆叠，编辑工具以抽屉呈现。
- 指标卡最小 2列/3行，图表最小 4列/6行，文本最小 3列/3行。

## 组件与质感
按钮高 36px、圆角 7px；输入高 38px；图表卡片圆角 12px；弹窗圆角 16px。卡片使用边框和轻阴影，选中显示蓝色边框。工具栏在选中或悬停时出现，触屏保持可见。深色导航、工作区、白色图表构成三级表面。
统一使用 Phosphor 线性图标。图表提供坐标轴、悬停提示、单位和口径入口。环形饼图配套图例及数值，不仅靠颜色识别。

## 交互与状态
- hover：浅底与边框变化；focus-visible：2px 蓝色轮廓；disabled：保留原因说明。
- 所有写入状态可识别：保存中、已保存、保存失败。失败保留本地恢复副本。
- 面板切换和状态反馈 160–200ms，无装饰性持续动画；减少动态偏好关闭动画。
- 生成任务可取消与收起；有未应用配置时切换组件需明确处理。
- 发布创建独立不可变快照。分享入口对应实际保存的发布版本。
- 图片和网页未配置时保留占位；图片错误、网页嵌入限制有回退入口。

## MVP 能力边界
本地单用户应用，SQLite 持久化、文件上传、独立发布快照。内置增长样例支持筛选和口径计算。AI 规则模式实际构建统一看板；配置模型凭据后通过服务端接入模型。界面明确标识生成模式及样例数据来源。
